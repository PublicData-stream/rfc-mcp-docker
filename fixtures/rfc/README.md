# Official RFC text fixtures

These complete, unchanged RFC Editor TXT files retain the original notices, page breaks, and other source bytes. The [provenance receipt](provenance.json) identifies their captures and terms. RFC 2119 states that distribution is unlimited. RFC 8174 contains its original notice and is included in full under IETF Trust Legal Provisions 5.0 section 3.c(i) for whole unmodified documents. These fixture terms apply independently of the application's MIT license. The fixture review covers whole-document reproduction.
