# 0012 — License-based redistribution and whole-corpus regex

This decision supersedes [0011](0011-automated-source-policy.md).

Apply affirmative grants to individual operations on authentic RFC text.
Verify the original digest and attach the required attribution and notices.
Run corpus search independently of permission to return matching text.
Return coordinates and the official source URL when rights permit search
and the requested bytes cannot be quoted.

Persist rights evidence independently of the source audit and publication
manifest. Keep the append-only restrictions ledger and authorization fence
across readable generations. Reclassify active and retained originals from
verified local data during the schema 13 cutover.
