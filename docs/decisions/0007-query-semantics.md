# 0007 — Exact, token, and relationship queries

Double-quoted literals match contiguous original bytes case-sensitively. Single-quoted literals use PostgreSQL `pg_catalog.simple` tokenization with every query term required across the RFC. Store only forward typed edges and evaluate inverse operators by reversing lookup direction. Missing evidence yields UNKNOWN. A negated predicate only includes a document when the evidence can establish the absence.

Use deterministic ICU `und` on the UTF-8 database for Unicode text behavior. Keep RFC keyset ordering numeric. Check the collation version and representative token, trigram, and sort behavior before any PostgreSQL image or ICU upgrade.
