# RFC MCP Docker

A read-only RFC research MCP service under development. Phase 1 provides immutable original-byte storage, PostgreSQL candidate generations, and storage checks for the Rust service images. The MCP entrypoint provides the Phase 0 protocol probe.

See [Implementation status](docs/implementation-status.md), [storage and database provisioning](docs/storage.md), [deployment prerequisites](docs/deployment-prerequisites.md), and [contributing](CONTRIBUTING.md).
